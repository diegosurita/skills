# Skills

This repository stores the AI agent skills I use in my daily development workflow. When I want a skill in a project I am working on, I ask the agent to download or update it from here.

## Get a skill

Each skill is a folder under `skills/`. Ask the agent to download or update that skill, and give it the folder's URL on GitHub:

```text
[Download or update] the skill <skill-name> from https://github.com/diegosurita/skills/tree/main/skills/<skill-name>]
```
